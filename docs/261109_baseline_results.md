# Baseline 모델 비교 결과

정리일: 2026-11-09 (한국 시간)

## 평가 조건

- 동일한 ICML Test 100문항, 데이터·프롬프트·평가기 동일.
- 문항당 단일 Responses API 요청, 외부 도구 없음, 추론 강도 `medium`.
- 최대 출력 예산 8,192토큰(내부 추론 포함), 요청 제한 시간 설정 180초.
- 마지막 `Answer: <정수>`를 파싱해 기존 라벨과 비교. 정답 외 상태는 모두 0점.
- 추가 평가 모델은 GPT-5.6 Luna와 GPT-5 Mini. GPT-5.4 nano 대신, 추론 문제의 비교 후보로 GPT-5 Mini를 선택함. 성능이 더 낮을 것이라는 보장은 두지 않음.
- 기존 두 실행은 재실행하지 않았고, 새 모델 두 개에 각각 Test 100문항 평가를 수행함.

추가 평가 두 모델의 개별 결과를 다시 집계해 요약 파일과 일치함을 확인했습니다. 네 실행의 Test ID, 데이터 해시, 입력 지시, 평가 코드 해시도 동일함을 확인했습니다.

## 해석

추가한 두 모델은 각각 83%, 84%로, 목표로 고려했던 60~70% 범위보다 높았습니다. 현재 비교에서는 기존 GPT-5.4 Mini의 77%가 가장 낮습니다. 이번 결과만으로 더 오래된 모델이나 더 작은 등급이면 정확도가 반드시 낮아진다고 볼 수 없습니다.

GPT-5 Mini는 GPT-5.4 Mini보다 7문항을 더 맞혔지만, 평균 응답 시간이 약 3배 길었고 출력 토큰도 더 많이 사용했습니다. GPT-5.6 Luna는 기존 GPT-6 Luna보다 2문항 적게 맞혔지만 이번 실행의 평균 응답 시간과 출력 토큰은 더 적었습니다. 1~2문항 차이를 확정적인 모델 우열로 해석하지는 않습니다.

새 실행의 `format_error`는 전부 모델이 연속변수 문제로 해석해 소수·분수 최적값을 얻고 정수 답을 정당화할 수 없다고 출력한 경우였습니다. 단순히 `Answer:` 표시를 잊은 경우와 구분할 필요가 있습니다. 현재 채점 규칙과 라벨은 변경하지 않았습니다.

| 추가 모델 | incorrect 문제 index | format_error 문제 index |
| --- | --- | --- |
| GPT-5.6 Luna | 42, 161, 181, 190, 191, 256, 334, 336, 370, 390, 392, 393, 401, 402 | 103, 258, 262 |
| GPT-5 Mini | 10, 42, 181, 190, 191, 256, 334, 370, 390, 393, 401, 402 | 103, 258, 262, 280 |

정확도는 제공된 정답 라벨과의 일치율입니다. 이 평가만으로 라벨의 수학적 정확성이나 모델의 데이터 암기 여부를 판별할 수는 없습니다.
