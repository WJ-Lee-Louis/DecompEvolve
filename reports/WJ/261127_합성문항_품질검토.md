# 합성 문항 품질 검토 · gpt-5.4-nano와 정확 solver

1. **정답의 기준을 먼저 고정한다.** gpt-5.4-nano는 원본 Train의 진단된 skill을 입력받아 변수·도메인·단위·목적식·제약식이 명시된 구조화 모형을 제안한다. 초기에는 현재 solver의 지원 범위인 유계 2변수 LP/IP로 제한하고, 정답은 solver가 계산한다. 범위를 확장하면 해당 모형에 맞는 최적성 상태와 정수성·수치 오차 검사를 추가한다.
2. **최종 문장을 검증한다.** 첫 버전은 검증된 모형에서 결정적으로 문장을 렌더링한다. gpt-5.4-nano가 자유롭게 문장을 쓰는 조건을 실험한다면 검수자는 정답과 원래 모형을 가린 채 문장만으로 재정식화한다. 변수명·단위·동치인 부등식을 정규화한 뒤 목적 방향·계수·도메인·제약의 대응을 대조한다. 정답이 우연히 같아도 조건이 누락되거나 해석이 갈리면 보류한다. 같은 계열 모델이 같은 오류를 낼 수 있어 유형별 사람 표본 검수도 별도로 한다.
3. **실수 판별력을 보존한다.** 정상 모형과 목표 실수를 적용한 모형의 최적값 차이를 검사한다. 목적식 문제는 ‘보고 금액 차이’와 ‘생산 계획 차이’를 구분한다. 수준별 추가 제약이 가능 영역 또는 최적해에 미친 영향과 실제 부모 정답률을 함께 본다. 모든 추가 제약이 반드시 최적값을 바꿔야 한다는 규칙은 두지 않는다.
4. **효과를 측정한다.** 구조화 진단만 적용한 조건과 전체 DecompEvolve를 비교한다. 풀이 모델, 원본 분할, 풀이 상한 1,200회, 합성 슬롯과 피드백 정책을 고정한다. 생성·검수 호출 토큰, 채택률·기각 사유, 출제된 문항 수, 구조적 중복률, 원본 검증에서 부모 대비 점수 변화를 기록한다. 합성 정답률 상승만으로 원본 LP 풀이 지침의 개선을 결론 내리기 어렵다.

## 원격 Train 파일럿 확인

원본 Train 13·88번에 모의 오류를 부여해 출제 경로를 점검했다. 최종 설정에서 nano 제안·수정 3회에 7,467토큰을 사용했다. 채택한 정수 문항은 정상 최적값 13, 목표 비례 제약을 제거한 값 25였다. 두 값을 별도 HiGHS 정수 최적화로 재계산해 일치를 확인했다. 두 번째 의뢰는 수정 후에도 목표 실수가 답을 바꾸지 않아 기각했다. 이 수치는 출제 검증 동작의 사례이며 학습 효과는 원본 Test에서 평가한다.
