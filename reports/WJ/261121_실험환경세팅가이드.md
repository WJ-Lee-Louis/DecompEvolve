# DecompEvolve 실험 환경 세팅 가이드

이미 복제해 둔 **DecompEvolve 폴더**를 코딩 에이전트에서 열고, 아래 프롬프트를 순서대로 붙여넣으세요. 환경을 준비하는 데는 **1번과 2번**이면 됩니다. 실제 모델을 호출해 볼 때는 **3번**을 사용하세요.

## 1. 최신 코드 받기 및 API 키 저장

**코딩 에이전트에 붙여넣기**

```text
현재 열린 폴더는 이미 복제한 DecompEvolve 저장소야. 나는 개발자가 아니니 명령은 네가 실행하고, 내가 직접 할 일만 짧게 알려줘.

1. 프로젝트용 Python 3.12 가상환경 .venv를 준비하고, 그 환경에 저장소와 GEPA·Modal 의존성을 설치해줘. 설치 옵션은 저장소 README를 참고해줘.
2. README.md가 있는 최상위 폴더에 .env가 Git 추적 대상에서 제외되는지 확인해줘. .env가 없으면 OPENAI_API_KEY=""와 EXAONE_API_KEY="" 두 줄로 만들어줘. 이미 있으면 기존 값을 유지하고 빠진 항목만 빈 값으로 추가해줘. 키 값은 채팅이나 명령 출력에 표시하지 말고, 내가 직접 편집할 파일의 경로만 알려줘.
3. API Baseline README의 --dry-run으로 데이터와 실행 설정이 정상인지 확인해줘. 실제 모델 API는 호출하지 마.
```

에이전트가 알려준 `.env`를 편집기에서 열어, 담당자가 **개별적으로 전달한 키**를 따옴표 안에 직접 넣고 저장하세요. 실제 키는 에이전트 채팅, Git, 공유 문서에 붙여넣지 마세요.

```dotenv
OPENAI_API_KEY="여기에 우진으로부터 카톡에 전달받은 OpenAI 키"
EXAONE_API_KEY="여기에 우진으로부터 카톡에 전달받은 LG EXAONE 키"
```

OpenAI를 요청하면 `OPENAI_API_KEY`를, LG EXAONE을 요청하면 `EXAONE_API_KEY`를 사용합니다. [API Baseline 실행 안내](../../experiments/api_baseline/README.md)

## 2. 내 Modal 계정 연결 및 원격 실행 확인

Modal에 가입하거나 로그인하고 본인 작업공간을 확인하세요. Starter의 무료 크레딧은 **작업공간당 월 30달러**이며 CPU와 메모리 등 Modal 컴퓨팅에 적용됩니다. OpenAI와 EXAONE 호출 비용은 각 API 계정에서 별도로 발생하며, Modal 크레딧 초과분도 청구될 수 있습니다. [Modal 가입](https://modal.com/signup) · [Modal 요금표](https://modal.com/pricing)

**코딩 에이전트에 붙여넣기**

```text
DecompEvolve 실험을 내 Modal 작업공간의 원격 CPU에서 실행할 수 있게 연결해줘.

1. 프로젝트 .venv에 Modal CLI를 설치하고 modal setup으로 내 계정을 연결해줘. 브라우저 로그인이 필요하면 내가 할 동작을 알려줘. 연결 후 modal token info로 사용할 작업공간을 확인하고, 토큰 값은 보여주지 마.
2. 이 실험용 API 키를 내 작업공간의 Modal Secret decompevolve-api-keys에 등록해줘. .env에 두 API 키만 들어 있다면 저장소 최상위에서 modal secret create --from-dotenv .env decompevolve-api-keys를 사용해줘. 다른 값도 들어 있거나 Secret이 이미 있다면, 내게 Modal 대시보드에서 해당하는 키만 등록하거나 갱신하는 방법을 알려줘. 키 값은 출력하지 말고 .env 파일 자체를 원격 이미지나 볼륨에 넣지 마.
3. modal run scripts/modal_experiments.py::smoke로 짧은 원격 CPU 테스트를 해줘. 원격 실행 여부, 데이터 분할 크기, 두 키의 설정 여부만 알려줘. 이 명령은 모델 API를 호출하지 않아.
4. 내가 확인할 Modal 작업공간 이름과 테스트 결과를 알려줘.
```

브라우저가 열리면 **본인 계정**으로 로그인하고, 에이전트가 알려준 작업공간이 맞는지 확인하세요. 두 키가 준비되지 않았다면 계정 연결까지 진행하고, 키를 받은 후 Secret을 등록하면 됩니다. [Modal 계정 연결](https://modal.com/docs/guide/getting-started) · [Modal Secret 등록](https://modal.com/docs/cli/latest/secret)

## 3. 이전 모델별 GEPA 실행 예시 (600회)

현재 nano 3조건 비교의 공통 상한은 1,200회입니다. 현재 명령과 집계 기준은 [DecompEvolve 실험 설계](../../experiments/decompevolve/README.md#1200회-비교-설계)를 따르세요. 아래는 이전 설정의 재현용 예시입니다.

1·2번에서 본인 Modal 작업공간과 담당 모델의 API 키를 연결한 뒤, **자기 모델의 제출 프롬프트**를 복사해 코딩 에이전트에 붙여넣으세요. 실행 링크와 ID를 저장해 두었다가, 실험이 끝난 뒤 **결과 받기 프롬프트**를 새로 붙여넣으세요.

두 실행은 같은 OptiMind IndustryOR 고정 분할을 사용합니다. Train 34문항에서 Easy·Medium·Hard 각 1문항씩 뽑고, Validation 20문항으로 프롬프트를 선택한 뒤 Test 30문항을 평가합니다. 풀이 호출의 상한은 문항당 15분과 추론을 포함한 생성 토큰 65,536개입니다. Train·Validation에는 최대 600회가 배정되며, 최종 Test 30회와 반성 호출은 별도입니다.

OpenAI 담당 모델은 **GPT-5.4 Mini**로 정했습니다. 기존 무도구 ICML Test 100문항에서 77%로 비교한 네 모델 중 가장 낮았고, 나머지 세 모델은 83~85%였습니다. 프롬프트 개선 여지를 관찰하기 위한 선택이며, OptiMind 성능은 이번 실험에서 확인합니다. [ICML Baseline 결과](../../experiments/api_baseline/docs/261109_baseline_results.md)

### 제출하기 · LG EXAONE 담당자

```text
내가 맡은 LG EXAONE GEPA 실험을 DecompEvolve 저장소의 기존 코드로 내 Modal 작업공간에서 실행해줘. 풀이와 반성 모두 k-exaone_v2.5를 사용해줘.

1. modal run scripts/modal_experiments.py::smoke로 내 Modal 작업공간에 EXAONE_API_KEY가 연결되어 있는지 확인해줘. 키 값은 출력하지 마. 아래 실행 명령에 --dry-run을 붙여 모델, OptiMind 분할 34/20/30, 풀이 호출 상한 600회를 확인하고, 실행 시드는 --seed 42를 사용해줘.
2. 확인이 끝나면 아래 명령으로 실제 실험을 제출해줘. 같은 실행 ID가 이미 있으면 기존 작업의 상태와 결과를 먼저 확인해줘.

modal run --detach scripts/modal_experiments.py::run --method gepa --provider exaone --model k-exaone_v2.5 --max-metric-calls 600 --parallelism 4 --seed 42 --run-id gepa-exaone-01

3. Modal에 작업이 제출됐고 내 PC를 꺼도 원격에서 계속되는 상태인지 확인해줘. Modal 실행 링크 또는 App ID, 실행 ID, 원격 결과 경로를 알려주고 이번 요청을 마쳐줘.
```

### 제출하기 · OpenAI 담당자

```text
내가 맡은 OpenAI GEPA 실험을 DecompEvolve 저장소의 기존 코드로 내 Modal 작업공간에서 실행해줘. 풀이와 반성 모두 gpt-5.4-mini-2026-03-17을 사용해줘.

1. modal run scripts/modal_experiments.py::smoke로 내 Modal 작업공간에 OPENAI_API_KEY가 연결되어 있는지 확인해줘. 키 값은 출력하지 마. 아래 실행 명령에 --dry-run을 붙여 모델, OptiMind 분할 34/20/30, 풀이 호출 상한 600회를 확인하고, 실행 시드는 --seed 42를 사용해줘.
2. 확인이 끝나면 아래 명령으로 실제 실험을 제출해줘. 같은 실행 ID가 이미 있으면 기존 작업의 상태와 결과를 먼저 확인해줘.

modal run --detach scripts/modal_experiments.py::run --method gepa --provider openai --model gpt-5.4-mini-2026-03-17 --max-metric-calls 600 --parallelism 4 --seed 42 --run-id gepa-openai-01

3. Modal에 작업이 제출됐고 내 PC를 꺼도 원격에서 계속되는 상태인지 확인해줘. Modal 실행 링크 또는 App ID, 실행 ID, 원격 결과 경로를 알려주고 이번 요청을 마쳐줘.
```

실제 실행에는 모델 API와 Modal 사용량이 발생하며, Modal은 비선점형 CPU 요금을 적용합니다. 로컬 컴퓨터를 닫은 뒤에는 받은 실행 링크에서 진행을 확인할 수 있습니다. Modal의 한 번 실행 제한은 24시간이며, 저장된 실행은 같은 ID로 재개합니다. [GEPA 실행 안내](../../experiments/gepa/README.md) · [Modal 분리 실행](https://modal.com/docs/guide/apps) · [Modal 비선점형 요금](https://modal.com/docs/guide/preemption)

### 나중에 결과 받기 · 두 담당자 공통

PC를 다시 켠 뒤, Modal에서 실행이 끝났으면 아래 프롬프트를 붙여넣으세요. 실행 ID는 기본 예시대로라면 EXAONE은 `gepa-exaone-01`, OpenAI는 `gepa-openai-01`입니다.

```text
전에 Modal에 제출한 GEPA 실험의 결과를 확인해줘.

Modal 실행 링크 또는 App ID [제출할 때 받은 값]
실행 ID [내 실행 ID]

1. Modal 상태와 결과 파일을 확인해줘. 실행 중이면 현재 상태를 알려줘. 체크포인트를 남기고 중단됐으면 상태와 기존 실행 명령에 --resume을 붙인 재개 명령을 알려줘.
2. Test 30문항까지 끝났으면 아래 명령에서 RUN_ID를 내 실행 ID로 바꿔 파일을 내려받아줘.

modal volume get decompevolve-results /gepa/RUN_ID runs/RUN_ID

3. python scripts/export_result.py runs/RUN_ID에서 RUN_ID를 내 실행 ID로 바꿔 Git 공유본을 만들어줘. 로컬 폴더와 Git 공유본 경로, test/summary.json의 전체 정확도 및 Easy/Medium/Hard별 정답 수, optimization.json의 Train·Validation 풀이 호출 수(task_api_calls_logged)를 알려줘.
```

프롬프트 개선 효과는 각 모델의 GEPA 결과를 **같은 모델의 OptiMind Baseline**과 짝지어 비교하세요. ICML 결과는 OpenAI 모델 선정 근거로 사용했습니다. [OptiMind Baseline 실행 안내](../../experiments/api_baseline/README.md)
