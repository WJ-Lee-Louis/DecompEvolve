## 윤서빈 · GEPA 실행

```text
나는 윤서빈이고 GEPA 조건 하나를 맡았어. 현재 열린 DecompEvolve 저장소에서 이전에 쓰던 가상환경과 내 Modal 프로필을 사용해줘. 아래 확인과 제출을 직접 진행하고 내가 해야 하는 조작만 알려줘.

1. 기존 프로필의 작업공간 이름과 현재 Git 커밋을 확인해줘. 이전에 쓰던 decompevolve-api-keys Secret으로 modal run scripts/modal_experiments.py::smoke를 실행해 remote=true, OpenAI 키 존재, 분할 34/20/30을 확인해줘. 키 값은 출력하지 마. 문제가 있으면 해당 항목만 안내해줘.
2. 아래 명령 끝에 --dry-run을 붙여 설정을 먼저 확인해줘. 풀이·반성 모델 모두 gpt-5.4-nano, max_metric_calls=1200, parallelism=4, max_synthetic_replacements=0이어야 해. 이 조건은 --method gepa야.
3. 내 작업공간에 같은 실행 ID가 있는지 확인해줘. 처음이면 아래 명령을 한 번 제출하고, 이미 실행 중이거나 완료됐으면 기존 실행을 사용해줘.

modal run --detach scripts/modal_experiments.py::run --method gepa --provider openai --model gpt-5.4-nano --seed 42 --max-metric-calls 1200 --parallelism 4 --auto-continue --run-id seobin-gepa-nano-1200-s42

4. 원격 로그와 결과 볼륨의 manifest.json을 확인하고, 작업공간·Git 커밋·Modal 실행 링크 또는 App ID·실행 ID를 알려줘. 볼륨은 decompevolve-results, 결과 폴더는 /gepa/seobin-gepa-nano-1200-s42야. PC를 꺼도 되는 시점도 알려줘.
```

## 이동규 · GEPA + 오류 진단 실행

```text
나는 이동규이고 GEPA에 오류 진단만 추가한 조건 하나를 맡았어. 현재 열린 DecompEvolve 저장소에서 이전에 쓰던 가상환경과 내 Modal 프로필을 사용해줘. 아래 확인과 제출을 직접 진행하고 내가 해야 하는 조작만 알려줘.

1. 기존 프로필의 작업공간 이름과 현재 Git 커밋을 확인해줘. 이전에 쓰던 decompevolve-api-keys Secret으로 modal run scripts/modal_experiments.py::smoke를 실행해 remote=true, OpenAI 키 존재, 분할 34/20/30을 확인해줘. 키 값은 출력하지 마. 문제가 있으면 해당 항목만 안내해줘.
2. 아래 명령 끝에 --dry-run을 붙여 설정을 먼저 확인해줘. 풀이·진단·반성 모두 gpt-5.4-nano, max_metric_calls=1200, parallelism=4여야 해. 특히 decompevolve.synthesis=false와 max_synthetic_replacements=0을 확인해줘. 이 조건은 --method decompevolve와 --diagnosis-only를 반드시 함께 사용해.
3. 내 작업공간에 같은 실행 ID가 있는지 확인해줘. 처음이면 아래 명령을 한 번 제출하고, 이미 실행 중이거나 완료됐으면 기존 실행을 사용해줘.

4. 원격 로그와 결과 볼륨의 manifest.json에서 decompevolve.synthesis=false를 확인하고, 작업공간·Git 커밋·Modal 실행 링크 또는 App ID·실행 ID를 알려줘. 볼륨은 decompevolve-results, 결과 폴더는 /decompevolve/donggyu-diag-nano-1200-s42야. PC를 꺼도 되는 시점도 알려줘.
```

## 완료 후 · 두 담당자 공통

실행 링크와 ID를 저장해 두세요. 나중에 **본인 실행 ID만** 아래 상자의 첫 줄에 넣어 코딩 에이전트에 붙여넣으면 됩니다.

```text
내 실행 ID는 [여기에 내 실행 ID 입력]이야. 제출에 사용한 Modal 프로필에서 이 실행의 결과를 확인해줘.

1. 실행 중이면 최근 진행 상황과 원격 링크를 알려줘. 세션 시간 때문에 다음 호출로 자동 재개됐는지도 확인해줘. 중단된 경우에는 후속 호출과 오류 로그를 확인한 뒤 같은 옵션·실행 ID에 --resume을 붙일 수 있는지 알려줘. 중복 실행은 만들지 마.
2. 볼륨 decompevolve-results에서 내 폴더를 찾아줘. 윤서빈은 /gepa/내실행ID, 이동규는 /decompevolve/내실행ID야. test/summary.json의 completed=true, records_written=30을 확인하고 modal volume get으로 해당 실행 폴더 전체를 runs/내실행ID에 내려받아줘.
3. 저장소 루트에서 python scripts/export_result.py runs/내실행ID로 공유본을 만들고, python scripts/summarize_budget.py runs/내실행ID로 역할별 호출 수와 토큰을 집계해줘. 명령의 내실행ID는 첫 줄의 실제 값으로 바꿔줘.
4. 내 이름과 실험 조건, Test 정답 수/30·정확도, Easy/Medium/Hard별 정답 수, Train+Validation 실제 풀이 호출 수, 진단·지침 수정 호출 수와 토큰, 공유본 폴더 경로를 한 번에 정리해줘. 내가 팀에 전달할 것은 이 요약과 공유본 폴더야.
```
