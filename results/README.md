## 완료 결과 내보내기

저장소 최상위에서 완료된 로컬 실행 폴더 또는 Modal에서 다운로드한 폴더를 지정하세요.

```bash
python scripts/export_result.py runs/gepa-openai-01
```

명령이 출력한 `results/<방법>/<모델>/<실행 ID>/` 경로를 Git에 추가하면 됩니다. Baseline에는 실행 설정, 문항별 응답과 채점 기록, 요약이 들어갑니다. GEPA에는 최종 Test 결과와 함께 선택된 프롬프트, 후보별 평가, 풀이와 반성 기록이 들어갑니다. 설계상 반성 호출이 없었던 실행에서는 `reflections.jsonl`이 생략됩니다.

공유본의 문항별 기록에는 공개 풀이 출력, 정답, 점수, 토큰 사용량, 응답 시간이 들어갑니다. 제공자의 응답 객체 전체와 재개용 체크포인트는 `runs/`의 원본에 보관합니다.
